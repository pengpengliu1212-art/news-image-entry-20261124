One image summing up the world news of Tuesday 24 November 2026: a news front
page carrying 50 stories, led by the Trump tariff plans. Built as an HTML front
page and rendered to a 1024×1024 PNG.

`main.ts` copies `entry.png` (the image beside it) into the output directory as
`entry.png`. Node 22, standard library only.

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
